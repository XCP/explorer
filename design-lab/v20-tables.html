TOUCHSTONES — the invariants every ported record table keeps.
  • time + block lead — relative time with the absolute UTC in title, block second; both left-aligned, mono, muted
  • one-line rows — every cell ellipsizes; nothing ever wraps, nothing card-stacks
  • units in headers — Price (sats), Total (BTC), Price (XCP); cells hold bare numbers, one denomination and one fixed recipe per column
  • chips = exceptions — a plain row gets no chip; green/red only on buy/sell words and signed values (lock polarity is the sanctioned exception)
  • full-address-title ellipsis — one full string under CSS ellipsis with a long visible prefix, complete value in title; never 4+4
  • hover place-keeping — row highlight on hover and keyboard focus is the only aid; no zebra, no flashing
